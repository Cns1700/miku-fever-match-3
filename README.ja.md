# ミク フィーバー マッチ3

*[English version here (英語版)](README.md)*

初音ミクと、5種類の着せ替え衣装 — さくら、25時（ナイトコード）、雪、レーシング、スペースシンガー — が登場する、無料・非営利のファンメイド・マッチ3パズルゲームです。お気に入りのミクを選び、モードを選択して、テーマごとに個性豊かな盤面をマッチさせながら進みましょう。各キャラクターには専用のアイコンセット、音楽、そして固有のスペシャル技があります。

ブラウザだけで遊べます。インストール不要、アカウント登録不要、広告なし。**[日本語・英語に対応](#言語について)** — 画面左上の言語切り替えボタンでいつでも切り替え可能です（プレイ中も切り替えられます）。

## 特徴

- **6人のプレイアブルなミク** — それぞれ独自のカラーパレット、盤面アイコン、音楽、効果音、そして固有のスペシャル技を持つ。
- **3つのゲームモード**：
  - **ステージクリア** — 全100レベル、手数制限あり。ステージ50に到達すると選べます：その場で勝利証明書を受け取るか、ステージ100を目指してさらに挑戦し、限定のレガシー証明書を狙うか。
  - **ライブパフォーマンス** — 90秒のタイムアタック、終盤に難易度が上昇。クリアすれば必ず勝利— 失敗という概念はなく、変わるのは最終スコアの高さだけです。
  - **リラックスモード** — タイマーなし、ゲームオーバーなし、ただのんびり遊べる。
- **フィーバーシステム** — 全モード共通。マッチを連鎖させてフィーバーレベルを上げ、節目でボーナスラウンドや報酬を獲得。
- **6種類の個性的なスペシャル技** — フィーバー獲得量を上げるクラシック・ミクの「ハーモニーウェーブ」、2つのタイルを指定し、それぞれ独立した3x3範囲を消せる（互いの範囲が重ならないよう常に距離を置いて選ばれる）さくらミクの「ブロッサムブラスト」、そして盤面を短時間自由に並べ替えられるスペースシンガーの「コズミックグラビティ」まで。
- **マッチ演出の強化** — タイルを消すとキャラクターのテーマカラーの粒子が舞い散り、補充されるタイルもただ出現するのではなく、重みを感じさせる動きで落ちてきます。
- **ダウンロード可能な結果証明書** — プレイ終了後に生成される、スコアとプレイしたキャラクターのポートレートが入ったシェア用画像。
- **日本語・英語の言語切り替え** — ヘッダーからいつでも切り替え可能（プレイ中も含む）。

## 遊び方

隣り合う2つのタイルをスワップして、同じアイコンを3つ以上、縦か横に並べてマッチさせましょう。タイルを消すとスコアとフィーバーゲージが増加し、マナバーを満タンにする（そのプレイで指定されたチャージ用アイコンをマッチさせる）とキャラクターのスペシャル技が解放されます。モードごと・キャラクターごとの詳しい説明はゲーム内に用意されています — いつでもゲーム内メニューの「遊び方」から確認できます。

## ローカルで動かす

ビルド不要、依存関係なし。以下のどちらかで動作します：

- `index.html` をブラウザで直接開く
- 任意の静的ファイルサーバーでフォルダを配信する（例：`python -m http.server` を実行し、`http://localhost:8000` にアクセス）
